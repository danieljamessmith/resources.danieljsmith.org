# src/

The Astro site: pages, layouts, components, styles and the catalogue data.
Read this before changing anything here. The rules for the content
(`public/tex/`) and for `src/data/` are in the root `AGENTS.md`.

## Site structure and presentation

The home page contains the Further Maths strand picker at `/#further-maths`, linking directly to `/further-maths/core-pure` and `/further-maths/further-mechanics`. The legacy `/further-maths` route redirects to `/#further-maths` (a generated HTML redirect on the static host). The shared header links directly to all three resource listings; from 1024px up it is a single sticky row whose height is the `--header-h` token, and the strand sidebar (sticky, independently scrollable) and anchor offsets (`--anchor-offset` → `scroll-padding-top`) derive from it. Below 1024px the header scrolls away and strand pages pin the board/topic pickers instead. All pages share one `.page-container` width. Internal links open in the same tab; only the viewer's raw "Open PDF" and external profile links open new tabs. A pack's documents are always listed in the order Questions | Mark scheme | Solutions, on its strand-page card (`ResourcePairCard.astro`) and in the viewer's links (`familyInOrder` in `resources.ts`); a pack without a mark scheme shows Questions | Solutions. The viewer's side by side pairs questions with their solutions, and a mark scheme or a TMUA answer key with its paper. The board filter dims non-matching booklets (they stay in place and clickable) and updates per-topic counts. Site-wide presentation lives in `src/styles/global.css` with the palette and font tokens declared in its `@theme` blocks: warm white, dark ink, burgundy accents, serif headings and ruled resource lists. Light mode is the default. `ThemeToggle.astro` switches the shared CSS colour variables, with the explicit choice persisted in `localStorage` under `resources-theme`; `Layout.astro` restores it before paint. The document and source headers also expose the toggle.

## Mobile site behaviour

Below 1024px, Further Maths pages use labelled native exam-board and topic selects; the desktop sidebar controls remain synchronised. Board selection dims non-matching booklets, preserves the topic fragment, and persists per strand. Topic selection updates the fragment and focuses the destination heading.

Below 768px, resource links marked `data-mobile-same-tab` use the current tab; `Layout.astro` updates their targets on load and viewport changes. Resource-row clicks in `src/scripts/board-filter.ts` follow the same breakpoint. Desktop links retain the new-tab workflow. The mobile PDF page includes a LaTeX source link where available. Mobile header tuition navigation is available in the footer; the theme toggle uses its accessible label with a compact icon.

## Search metadata

`Layout.astro` supplies absolute, trailing-slash canonical URLs and Open Graph/Twitter metadata. Pages share the square logo by default; a page can pass a wide `shareImage` (which also switches the Twitter card to `summary_large_image`). TMUA pages pass `TMUA_SHARE_IMAGE` from `resources.ts`, built from `og-images/`; it deliberately states no counts so it cannot go stale. The TMUA listing's description is built from `getTmuaStats()` (sets, papers, questions, questions with worked solutions), so its counts update with the catalogue. Internal page links must also end in `/` (e.g. `/tmua/`, `/view/<id>/`) so they match the canonical and avoid the host's 301; `trailingSlash: 'always'` in `astro.config.mjs` makes the dev server 404 on a missing slash. Document titles distinguish questions, answer keys, mark schemes and worked solutions. Source viewers are generated only for existing LaTeX files and marked `noindex, follow`; the sitemap excludes source viewers, the 404 page and the legacy Further Maths redirect. `public/robots.txt` points crawlers at the sitemap index and disallows raw `.tex` files, which are linked only from the noindexed source viewers.
