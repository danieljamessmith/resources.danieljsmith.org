\questionitem
% [Source: _QBT___Solns__Proof_by_Induction___Divisibility, Q1]

Prove by induction that \[n^5-n\] is divisible by $5$ for all positive integers $n$ \marks{6}

\vspace*{10pt}

\begin{djsSolution}
We prove by induction that \(n^5-n\) is divisible by \(5\) for all positive integers \(n\).

\textbf{Base case:} \(n=1\). Then
\[
1^5-1=1-1=0
\]

This is divisible by \(5\), so the statement is true for \(n=1\).

\textbf{Inductive hypothesis:} Assume the statement is true for \(n=k\), where \(k\) is a positive integer. That is, assume
\[
k^5-k \text{ is divisible by } 5
\]

so there is an integer \(m\) such that
\[
k^5-k=5m
\]

\textbf{Inductive step:} We must show that \((k+1)^5-(k+1)\) is also divisible by \(5\).

Let \(f(n)=n^5-n\). Then
\[
f(k+1)=f(k)+\bigl(f(k+1)-f(k)\bigr)
\]

Now calculate the difference:
\begin{align*}
f(k+1)-f(k)
&=\bigl((k+1)^5-(k+1)\bigr)-\bigl(k^5-k\bigr)\\
&=(k+1)^5-k^5-1\\
&=\left(k^5+5k^4+10k^3+10k^2+5k+1\right)-k^5-1\\
&=5k^4+10k^3+10k^2+5k\\
&=5(k^4+2k^3+2k^2+k)
\end{align*}

So
\[
(k+1)^5-(k+1)=(k^5-k)+5(k^4+2k^3+2k^2+k)
\]

By the inductive hypothesis, \(k^5-k\) is divisible by \(5\).
Also, \(5(k^4+2k^3+2k^2+k)\) is clearly divisible by \(5\).

Therefore \((k+1)^5-(k+1)\) is divisible by \(5\), so the statement is true for \(n=k+1\).

\textbf{Conclusion:} If the statement is true for \(n=k\), then it is true for \(n=k+1\). Since it is true for \(n=1\), by the principle of mathematical induction the statement is true for all positive integers \(n\).
\end{djsSolution}

\questionitem
% [Source: _QBT___Solns__Proof_by_Induction___Divisibility, Q2]

For each positive integer $n$, define

\[u_n=5^{2n}-2^n\]

Use proof by induction to show that $23$ is a factor of $u_n$ for all $n \in \mathbb{Z}^+$ \marks{6}

\vspace*{10pt}

\begin{djsSolution}
We prove by induction that \(u_n=5^{2n}-2^n\) is divisible by \(23\) for all \(n\in\mathbb{Z}^+\).

\textbf{Base case:} \(n=1\). Then
\[
u_1=5^{2}-2^1=25-2=23
\]

This is divisible by \(23\), so the statement is true for \(n=1\).

\textbf{Inductive hypothesis:} Assume the statement is true for \(n=k\), where \(k\) is a positive integer. That is, assume
\[
u_k \text{ is divisible by } 23
\]

so there is an integer \(m\) such that
\[
u_k=5^{2k}-2^k=23m
\]

\textbf{Inductive step:} Now consider \(u_{k+1}\):
\begin{align*}
u_{k+1}
&=5^{2(k+1)}-2^{k+1}\\
&=5^{2k+2}-2\times 2^k\\
&=25\times 5^{2k}-2\times 2^k\\
&=(23+2)5^{2k}-2\times 2^k\\
&=23\times 5^{2k}+2\times 5^{2k}-2\times 2^k\\
&=23\times 5^{2k}+2\left(5^{2k}-2^k\right)
\end{align*}

Using the inductive hypothesis \(5^{2k}-2^k=23m\):
\begin{align*}
u_{k+1}
&=23\times 5^{2k}+2(23m)\\
&=23\left(5^{2k}+2m\right)
\end{align*}

Since \(5^{2k}+2m\) is an integer, \(u_{k+1}\) is divisible by \(23\), so the statement is true for \(n=k+1\).

\textbf{Conclusion:} If the statement is true for \(n=k\), then it is true for \(n=k+1\). Since it is true for \(n=1\), by the principle of mathematical induction the statement is true for all \(n\in\mathbb{Z}^+\).
\end{djsSolution}

\questionitem
% [Source: _QBT___Solns__Proof_by_Induction___Divisibility, Q3]

Prove by induction that \[9^n-8n-1\] is divisible by $64$ for all positive integers $n$ \marks{6}

\vspace*{10pt}

\begin{djsSolution}
We prove by induction that \(9^n-8n-1\) is divisible by \(64\) for all positive integers \(n\).

\textbf{Base case:} \(n=1\). Then
\[
9^1-8(1)-1=9-8-1=0
\]

This is divisible by \(64\), so the statement is true for \(n=1\).

\textbf{Inductive hypothesis:} Assume the statement is true for \(n=k\), where \(k\) is a positive integer. That is, assume
\[
9^k-8k-1 \text{ is divisible by } 64
\]

so there is an integer \(m\) such that
\[
9^k-8k-1=64m
\]

\textbf{Inductive step:} Now consider \(9^{k+1}-8(k+1)-1\):
\begin{align*}
9^{k+1}-8(k+1)-1
&= 9\times 9^k-8k-8-1 \\
&= 9\times 9^k-8k-9 \\
&= 9(9^k-8k-1)+64k
\end{align*}

Now use the inductive hypothesis \(9^k-8k-1=64m\):
\begin{align*}
9^{k+1}-8(k+1)-1
&= 9(64m)+64k \\
&= 64(9m+k)
\end{align*}

Since \(9m+k\) is an integer, \(9^{k+1}-8(k+1)-1\) is divisible by \(64\), so the statement is true for \(n=k+1\).

\textbf{Conclusion:} If the statement is true for \(n=k\), then it is true for \(n=k+1\). Since it is true for \(n=1\), by the principle of mathematical induction the statement is true for all positive integers \(n\).
\end{djsSolution}

\questionitem
% [Source: _QBT___Solns__Proof_by_Induction___Divisibility, Q4]

Prove by mathematical induction that, for all non-negative integers $n$,
\[
2^n+2\times 3^{2n}+4^{2n+1}
\]
is divisible by $7$ \marks{6}

\vspace*{10pt}

\begin{djsSolution}
We prove by induction that \(2^n + 2\times 3^{2n} + 4^{2n+1}\) is divisible by \(7\) for all non-negative integers \(n\).

\textbf{Base case:} \(n=0\). Then
\[
2^0 + 2\times 3^0 + 4^1 = 1+2+4=7
\]

This is divisible by \(7\), so the statement is true for \(n=0\).

\textbf{Inductive hypothesis:} Assume the statement is true for \(n=k\), where \(k\) is a non-negative integer. That is, assume
\[
2^k + 2\times 3^{2k} + 4^{2k+1} \text{ is divisible by } 7
\]

so there is an integer \(m\) such that
\[
2^k + 2\times 3^{2k} + 4^{2k+1} = 7m
\]

\textbf{Inductive step:} We must show that
\[
2^{k+1} + 2\times 3^{2k+2} + 4^{2k+3}
\]

is divisible by \(7\).

Starting with this expression:
\begin{align*}
2^{k+1} + 2\times 3^{2k+2} + 4^{2k+3}
&= 2\times 2^k + 2\times 3^2\times 3^{2k} + 4^2\times 4^{2k+1} \\
&= 2\times 2^k + 18\times 3^{2k} + 16\times 4^{2k+1} \\
&= 2\bigl(2^k + 2\times 3^{2k} + 4^{2k+1}\bigr) + 14\times 3^{2k} + 14\times 4^{2k+1}
\end{align*}

Now use the inductive hypothesis \(2^k + 2\times 3^{2k} + 4^{2k+1}=7m\):
\begin{align*}
2^{k+1} + 2\times 3^{2k+2} + 4^{2k+3}
&= 2(7m) + 14\times 3^{2k} + 14\times 4^{2k+1} \\
&= 14m + 14\bigl(3^{2k} + 4^{2k+1}\bigr) \\
&= 7\bigl(2m + 2\times 3^{2k} + 2\times 4^{2k+1}\bigr)
\end{align*}

Since \(2m + 2\times 3^{2k} + 2\times 4^{2k+1}\) is an integer, \(2^{k+1} + 2\times 3^{2k+2} + 4^{2k+3}\) is divisible by \(7\), so the statement is true for \(n=k+1\).

\textbf{Conclusion:} If the statement is true for \(n=k\), then it is true for \(n=k+1\). Since it is true for \(n=0\), by the principle of mathematical induction the statement is true for all non-negative integers \(n\).
\end{djsSolution}

\questionitem
% [Source: _QBT___Solns__Proof_by_Induction___Divisibility, Q5]

Prove by induction that, for $n \in \mathbb{Z}^+$,

\[
7^n-6n-1
\]

is divisible by $36$ \marks{6}

\vspace*{10pt}

\begin{djsSolution}
We prove by induction that \(7^n-6n-1\) is divisible by \(36\) for all \(n\in\mathbb{Z}^+\).

\textbf{Base case:} \(n=1\). Then
\[
7^1-6(1)-1=7-6-1=0
\]

This is divisible by \(36\), so the statement is true for \(n=1\).

\textbf{Inductive hypothesis:} Assume the statement is true for \(n=k\), where \(k\) is a positive integer. That is, assume
\[
7^k-6k-1 \text{ is divisible by } 36
\]

so there is an integer \(m\) such that
\[
7^k-6k-1=36m
\]

\textbf{Inductive step:} We must show that
\[
7^{k+1}-6(k+1)-1
\]

is divisible by \(36\).

Starting with this expression:
\begin{align*}
7^{k+1}-6(k+1)-1
&=7^{k+1}-6k-6-1\\
&=7^{k+1}-6k-7
\end{align*}

Now rewrite it to use the inductive hypothesis:
\begin{align*}
7^{k+1}-6k-7
&=7\times 7^k-6k-7\\
&=7(7^k-6k-1)+36k
\end{align*}

Using the inductive hypothesis \(7^k-6k-1=36m\):
\begin{align*}
7^{k+1}-6(k+1)-1
&=7(36m)+36k\\
&=36(7m+k)
\end{align*}

Since \(7m+k\) is an integer, \(7^{k+1}-6(k+1)-1\) is divisible by \(36\), so the statement is true for \(n=k+1\).

\textbf{Conclusion:} If the statement is true for \(n=k\), then it is true for \(n=k+1\). Since it is true for \(n=1\), by the principle of mathematical induction the statement is true for all \(n\in\mathbb{Z}^+\).
\end{djsSolution}

\questionitem
% [Source: _QBT___Solns__Proof_by_Induction___Divisibility, Q6]

The function $f$ is defined by
\[
f(n)=9^n-8n+63 
\] 
Prove by induction that $f(n)$ is divisible by $64$ for $n \geq 1$ \marks{6}

\vspace*{10pt}

\begin{djsSolution}
We prove by induction that \(f(n)=9^n-8n+63\) is divisible by \(64\) for all \(n\ge 1\).

\textbf{Base case:} \(n=1\). Then
\[
f(1)=9^1-8(1)+63=9-8+63=64
\]

This is divisible by \(64\), so the statement is true for \(n=1\).

\textbf{Inductive hypothesis:} Assume the statement is true for \(n=k\), where \(k\) is a positive integer. That is, assume
\[
f(k)=9^k-8k+63 \text{ is divisible by } 64
\]

so there is an integer \(m\) such that
\[
9^k-8k+63=64m
\]

\textbf{Inductive step:} Now consider \(f(k+1)\):
\begin{align*}
f(k+1)
&=9^{k+1}-8(k+1)+63 \\
&=9\times 9^k-8k-8+63 \\
&=9\times 9^k-8k+55
\end{align*}

We now rewrite this in terms of \(f(k)=9^k-8k+63\):
\begin{align*}
f(k+1)
&=9(9^k-8k+63)+72k-567-8k+55 \\
&=9(9^k-8k+63)+64k-512 \\
&=9(9^k-8k+63)+64(k-8)
\end{align*}

Using the inductive hypothesis \(9^k-8k+63=64m\):
\begin{align*}
f(k+1)
&=9(64m)+64(k-8) \\
&=64(9m+k-8)
\end{align*}

Since \(9m+k-8\) is an integer, \(f(k+1)\) is divisible by \(64\), so the statement is true for \(n=k+1\).

\textbf{Conclusion:} If the statement is true for \(n=k\), then it is true for \(n=k+1\). Since it is true for \(n=1\), by the principle of mathematical induction the statement is true for all \(n\ge 1\).
\end{djsSolution}

\questionitem
% [Source: _QBT___Solns__Proof_by_Induction___Divisibility, Q7]

Prove by mathematical induction that
\[
7^{2n}+8\times 13^n-9
\]
is divisible by $36$ for all positive integers $n$ \marks{6}

\vspace*{10pt}

\begin{djsSolution}
Let
\[
E_n=7^{2n}+8\times 13^n-9
\]

We prove by induction that \(E_n\) is divisible by \(36\) for all positive integers \(n\).

\textbf{Base case:} \(n=1\). Then
\begin{align*}
E_1&=7^2+8\times 13-9\\
&=49+104-9\\
&=144\\
&=36\times 4
\end{align*}

This is divisible by \(36\), so the statement is true for \(n=1\).

\textbf{Inductive hypothesis:} Assume the statement is true for \(n=k\), where \(k\) is a positive integer. That is, assume
\[
E_k=7^{2k}+8\times 13^k-9 \text{ is divisible by } 36
\]

so there is an integer \(m\) such that
\[
7^{2k}+8\times 13^k-9=36m
\]

\textbf{Inductive step:} Consider \(E_{k+1}\):
\begin{align*}
E_{k+1}
&=7^{2(k+1)}+8\times 13^{k+1}-9\\
&=7^{2k+2}+8\times 13^{k+1}-9\\
&=49\times 7^{2k}+104\times 13^k-9
\end{align*}

Now rewrite this so that \(E_k\) appears:
\begin{align*}
E_{k+1}
&=13\times 7^{2k}+36\times 7^{2k}+13\times 8\times 13^k-117+108\\
&=13\left(7^{2k}+8\times 13^k-9\right)+36\left(7^{2k}+3\right)\\
&=13E_k+36\left(7^{2k}+3\right)
\end{align*}

Using the inductive hypothesis \(E_k=36m\):
\begin{align*}
E_{k+1}
&=13(36m)+36\left(7^{2k}+3\right)\\
&=36\left(13m+7^{2k}+3\right)
\end{align*}

Since \(13m+7^{2k}+3\) is an integer, \(E_{k+1}\) is divisible by \(36\), so the statement is true for \(n=k+1\).

\textbf{Conclusion:} If the statement is true for \(n=k\), then it is true for \(n=k+1\). Since it is true for \(n=1\), by the principle of mathematical induction the statement is true for all positive integers \(n\).
\end{djsSolution}

\questionitem
% [Source: _QBT___Solns__Proof_by_Induction___Divisibility, Q8]

Prove by induction that, for $n \in \mathbb{Z}^+$,
\[13^n+3\times 4^n+11\] is divisible by $12$ \marks{6}

\vspace*{10pt}

\begin{djsSolution}
We prove by induction that \(13^n+3\times 4^n+11\) is divisible by \(12\) for all \(n\in\mathbb{Z}^+\).

\textbf{Base case:} \(n=1\). Then
\[
13^1+3\times 4^1+11=13+12+11=36=12\times 3
\]

This is divisible by \(12\), so the statement is true for \(n=1\).

\textbf{Inductive hypothesis:} Assume the statement is true for \(n=k\), where \(k\) is a positive integer. That is, assume
\[
13^k+3\times 4^k+11 \text{ is divisible by } 12
\]

so there is an integer \(m\) such that
\[
13^k+3\times 4^k+11=12m
\]

\textbf{Inductive step:} We must show that \(13^{k+1}+3\times 4^{k+1}+11\) is divisible by \(12\).

Consider the difference:
\begin{align*}
&\left(13^{k+1}+3\times 4^{k+1}+11\right)-\left(13^k+3\times 4^k+11\right) \\
&= 13^{k+1}-13^k+3\times 4^{k+1}-3\times 4^k \\
&= 13^k(13-1)+3\times 4^k(4-1) \\
&= 12\times 13^k+9\times 4^k \\
&= 12\times 13^k+12\left(3\times 4^{k-1}\right)
\end{align*}

Since \(k\geq 1\), \(4^{k-1}\) is an integer, so this whole difference is a multiple of \(12\).

Therefore
\begin{align*}
13^{k+1}+3\times 4^{k+1}+11
&= \left(13^k+3\times 4^k+11\right)
 + \left[\left(13^{k+1}+3\times 4^{k+1}+11\right)-\left(13^k+3\times 4^k+11\right)\right] \\
&= 12m + 12\times 13^k + 12\left(3\times 4^{k-1}\right) \\
&= 12\left(m+13^k+3\times 4^{k-1}\right)
\end{align*}

Since \(m+13^k+3\times 4^{k-1}\) is an integer, \(13^{k+1}+3\times 4^{k+1}+11\) is divisible by \(12\), so the statement is true for \(n=k+1\).

\textbf{Conclusion:} If the statement is true for \(n=k\), then it is true for \(n=k+1\). Since it is true for \(n=1\), by the principle of mathematical induction the statement is true for all \(n\in\mathbb{Z}^+\).
\end{djsSolution}
