# resources.danieljsmith.org

Free study materials: A-level Further Maths question packs with worked
solutions and mark schemes, TMUA papers with answer keys and solutions, and
notes, each readable in the browser or downloaded as a PDF.

Built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com),
deployed to GitHub Pages from `main`. `npm ci`, then `npm run dev` to serve
it locally; `npm test` and `npm run check` are what CI runs. Working rules
for the repo are in [AGENTS.md](AGENTS.md); the site's presentation is
described in [src/README.md](src/README.md).
